Приложение предназначено для подбора близких по своим параметрам торговых точек. Набор параметров, по которым ведется поиск гибко настраивается пользователем, через виджеты. Значения параметров, выбранных пользователем, для конкретных торговых точек осуществляются в приложении по заранее запрограммированной логике. После расчета пользователь может скачать Excel файл содержащий подобранные торговые точки и значения параметров, по которым был осуществлен подбор. Если для точки не удалось подобрать схожую, то в файле это также указано.

Структура приложения в тетради matchmaker.ipynb следующая:  
Файл состоит из разделов:

1. ЗАГРУЗКА И ПОДГОТОВКА ДАННЫХ - В этом разделе мы загружаем данные, которые служат основой для расчета параметров, по которым будут подбираться торговые точки.
2. ЗАГРУЗКА СПИСКА ТЕСТОВЫХ ТОЧЕК И ВЫБОР ПАРАМЕТРОВ ПОДБОРА ПАР - В этом разделе пользователь загружает в систему тестовые точки, для которых потому нужно будет подобрать контрольные, указывает параметры, по которым нужно производить подбор и конфигурирует допуски по отклонению от этих параметров.
3. БЛОК ЛОГИКИ ДЛЯ ПОИСКА КОНТРОЛЬНЫХ ТОЧЕК - В этом разделе прописаны функции, содержащие логику по подборы контрольных точек
4. ПОДБОР ПАР И ВЫГРУЗКА РЕЗУЛЬТАТОВ - В этом разделе содержатся виджеты позволяющие запустить процесс подбора и выгрузить результаты.

Постарайся придерживаться этой структуры разделов.

Каждая ячейка начинается с текстовой строки, в которой содержится её номер, назначение и иногда описание структуры данных, которые загружаются для последующей обработки. Внимательно прочитай их чтобы уяснить себе логику приложения.
